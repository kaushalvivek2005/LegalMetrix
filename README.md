# LegalMetrix

### Digital Legal Metrology Verification & Certification Platform

LegalMetrix is a web-based platform designed to digitize and streamline the verification and certification lifecycle of weighing and measuring instruments.

## Features

- Instrument registration and management
- Online verification application
- Verification status tracking
- LMO/GATC assignment and scheduling
- Digital field inspection workflow
- Offline-first inspection data capture
- Geo-tagged inspection evidence
- PASS/FAIL verification workflow
- Digital certificate generation
- QR-based certificate verification
- Verification history and audit trail
- Role-based dashboards

## Tech Stack

- React.js
- Vite
- JavaScript / JSX
- Tailwind CSS
- React Router
- Recharts
- Lucide React
